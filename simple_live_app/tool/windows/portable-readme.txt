Simple Live Windows 便携版

1. 将 ZIP 完整解压到任意目录，双击「Simple Live.exe」。
2. runtime 文件夹包含播放器、插件和 Flutter 资源。请完整保留，可随整个目录一起移动。
3. 可右键「Simple Live.exe」创建快捷方式。快捷方式可放在桌面，无需复制运行库。
4. 便携版指无需安装；收藏、设置和日志仍存储在当前 Windows 用户的应用数据目录，升级不会覆盖。
5. 更新时关闭所有直播窗口，将新包解压到新目录后启动。
6. 遇到问题：其他设置 → 导出诊断包。默认记录错误，开启「详细调试日志」后复现可提供更多信息。
7. 日志按窗口/进程分开，自动轮转；「清空日志」保留仍在使用的日志。

MSIX 安装版也会单独发布，安装后通过开始菜单启动。
